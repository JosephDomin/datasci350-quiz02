This page compares film runtimes with IMDb ratings. In @fig-runtime-rating, each point represents one film.

```{python}
#| echo: true
#| fig-cap: "Film runtime in minutes and IMDb rating"
#| label: fig-runtime-ratubgs

plt.scatter(films["runtime_min"], films["imdb_rating"])
plt.xlabel("Runtime (minutes)")
plt.ylabel("IMDb rating (0–10)")
plt.show()
```
## Mean Rating Per Decade

This graph shows mean rating per decade
```{python}
films["decade"] = films["year"] // 10 * 10
films.groupby("decade")["imdb_rating"].mean().round(2)
```

title: "The Bond Films"
jupyter: python3
---

```{python}
#| echo: true
import pandas as pd
import matplotlib.pyplot as plt

films = pd.read_csv("films.csv")

bond = films[films["franchise"] == "James Bond"]
bond = bond.sort_values("year") - sorting chronologically 
```

The Bond films in this dataset run from `{python} int(bond["year"].min())` to `{python} int(bond["year"].max())`.

```{python}
#| echo: true
#| fig-cap: "Worldwide revenue of James Bond films over time."
#| label: fig-bond-revenue

plt.plot(bond["year"], bond["revenue_musd"])
plt.xlabel("Release year")
plt.ylabel("Worldwide revenue (millions of US dollars)")
plt.show()
```
